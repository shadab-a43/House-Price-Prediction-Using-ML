# House Price Prediction Using Machine Learning

An end-to-end Machine Learning project focused on predicting residential house prices using Python and Scikit-learn.

## Project Overview

The goal of this project is to understand the complete Machine Learning workflow, from dataset inspection and exploratory data analysis to model training and evaluation.

The project uses the Ames Housing dataset to predict house sale prices.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit (planned)

## Dataset

- **Dataset:** Ames Housing Dataset
- **Records:** 2,930
- **Features:** 82 columns
- **Target Variable:** `SalePrice`

The dataset contains residential property information from Ames, Iowa, USA.
